# R5 StreamerHub

Streamtool voor Twitch: overzicht van je eigen kanaal (live-status, kijkers, volgers, subs, bits, raids, chat) en overlays voor OBS (emote-wall, emote-combo, raid-melding).

Live op https://r5streamer.daver5.nl/ · zusje van [R5 ModHub](https://r5mod.daver5.nl/).

- `index.html`: de app (één bestand, geen build).
- `overlay.html`: de overlays als OBS-browserbron; instellingen staan in de link, leest de chat anoniem.
