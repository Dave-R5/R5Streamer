# Oud adres r5streamer.daver5.nl

Deze map hoort in een eigen, kleine repo waarvan GitHub Pages het oude adres **r5streamer.daver5.nl** serveert.
Elke pagina (`index.html` en `404.html` zijn gelijk) stuurt door naar hetzelfde pad op **streamerhub.r5mod.nl**,
zodat oude links, bladwijzers en OBS-bronnen blijven werken. Op de startpagina gaan de instellingen mee.
Windows-apps ouder dan 1.3.0 krijgen hier een knop om eerst bij te werken.
